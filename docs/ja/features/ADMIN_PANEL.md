# 管理パネル

管理メニューの Panorama 版パネルです。`!admin` → 「パネルを開く」で開きます。インスペクトキー (既定 F) を押している間だけカーソルを使えるので、
パネルを開いたままでもゲームは操作できます。

クライアントに Wuling Liuli の addon (`csgo_addons/panorama_layout`、パネルも一緒にビルドされます) が必要です。

## 権限

| 権限 | できること |
|---|---|
| `tnms.adminutil.panel` | パネルを開く (`!admin` の「パネルを開く」) |
| `tnms.adminutil.panel.ip` | プレイヤーの IP アドレスを見る |
| `tnms.adminutil.panel.dev` | Dev ページ。権限が無いとヘッダーに Dev ボタンが出ません |

## ページ

ページはヘッダーバーに並び、サイドバーには今のページの項目が並びます。

| ページ | 内容 |
|---|---|
| 概要 | マッチ (サイドバー): マップ、ラウンド時間、スコア、チームの人数 |
| ユーザー一覧 | プレイヤーの一覧 (サイドバーでチーム絞り込み)。行を押すとそのプレイヤーの詳細と、そのプレイヤーへのコマンドを開きます |
| コマンド | お気に入り / すべて / カテゴリと、選んだコマンドのフォーム ([ADMIN_MENU](ADMIN_MENU.md) を参照) |
| Dev | サーバーの状態、バージョン、読み込み中のモジュール |

## 一覧

カーソルが出ている間、一覧はマウスホイールでスクロールできます (Panorama がクライアント側でスクロールします)。

| 一覧 | 1ページの数 |
|---|---|
| サイドバー | 32。それを超えると先頭 / 末尾に「前へ / 次へ」 |
| コマンド一覧 | 64。それを超えると下にページ送りのバー (‹ 前へ \| 2 / 3 \| 次へ ›) |
| ユーザー一覧 | 64 (サーバーの最大人数) |
| フォームの選択肢 | 48、3行分の高さ。それを超えると下に ‹ › |
| モジュール / 依存アセンブリ (Dev) | 64。それを超えるとページ送りのバー |

表示する中身が変わると (タブ・ページ・プレイヤー・絞り込み・並び替え)、一覧は先頭に戻ります。
同じ一覧に戻ったとき (モジュールの詳細から戻るなど) はスクロール位置がそのまま残ります。

コマンド一覧は1列で、開いたコマンドのフォームは常にその右に出ます (開いていないときは「左の一覧からコマンドを選んでください」)。
フォームを開閉しても一覧の位置は変わりません。

## 検索

コマンドのサイドバー (コマンドページとプレイヤーのコマンド) の一番上の「検索」で検索タブを開きます。一覧の上に検索欄があり、
押すとチャットで検索語を入力できます (入力待ちの間は金色)。もう一度押すと中止します。✕ で検索語を消します。
検索語がまだ無いときは、タブを開いた時点で入力待ちになります。

- チャットの発言はすべて検索語になります (`cancel` も検索できます)。
- 別のタブ・ページへ移るか、60秒たっても入力待ちは終わります。
- コマンド名・表示名・説明文・カテゴリ名のどれかに、すべての語が含まれるコマンドが一致します (大文字小文字は区別しません)。
- プレイヤーのコマンドから検索すると、対象を取るコマンドだけを探します。
- 検索語はクリアするかパネルを閉じるまで残り、コマンドページとプレイヤーのコマンドで共通です。
- 件数はパンくずの後ろに出ます。

## フォームの文字入力

文字が必要なフィールド (と、選択肢の「チャットで入力」) は、次のチャット発言を待ちます。入力待ちのフィールドをもう一度押すと中止します。
パネルでは `cancel` と打っても値として扱われます。60秒で無効になります。

対象のフィールドには、チャットで任意の対象を入力できます (プラグインのセレクター `@zombies`、名前、SteamID64 など)。
TargetingManager で解決し、当てはまるプレイヤーがいなければもう一度聞きます。1人だけ指定できるフィールドは、ちょうど1人に当たる入力だけを受け付けます。

パネル (またはチャットのメニュー) が文字入力を待っている間は、管理者チャット (`@...`) がその発言を拾いません。セレクターを打っても管理者に送られません。

## Dev

値は1秒ごとに更新されます。

### サーバー

| グループ | 項目 |
|---|---|
| パフォーマンス | ティックレートとサーバー FPS (直近1秒の実測)、フレーム時間、フレームのばらつき、ティック |
| 稼働時間 | サーバー稼働 (プロセス)、マップ経過、サーバー時刻 |
| リソース | プロセスメモリ、マネージドヒープ、GC 回数 (世代 0 / 1 / 2)、エンティティ / MaxEntities |
| 接続 | プレイヤー、Bot、接続中、スロット (接続数 / MaxClients) |

ティックレートと FPS は、2回目の計測 (プラグインの読み込みから1秒後) までは `-` です。エンティティはページを表示している間、index を走査して数えます。

### バージョン

| グループ | 項目 |
|---|---|
| 実行環境 | ModSharp、Sharp.Shared、CS2 (`csgo/steam.inf` の `PatchVersion` と日付)、.NET、OS |
| コンポーネント | TnmsAdminUtils、TnmsPluginFoundation、Wuling.Abstract |

commit hash 付きのバージョンは hash の先頭7文字を表示します。

### プラグイン

読み込み中の ModSharp モジュール (名前、表示名、作者、バージョン。状態が Running 以外のときは状態も) を、マウスホイールでスクロールできる1つの一覧に最大 64 個表示します。行を押すとそのモジュールの詳細を開きます。

- モジュール: 名前、表示名、作者、状態、バージョン、モジュールのクラス、ターゲットフレームワーク、ビルド構成、説明、リポジトリ URL
  (最後の2つはモジュールの csproj に書かれている場合のみ)。
- 依存アセンブリ: そのモジュールのロードコンテキストにある他のアセンブリ (モジュールが自分で同梱しているもの。共有ライブラリは別の場所で読み込まれます)。
  スクロールでき、1ページ 64 個ずつ。

ModSharp にはモジュールを一覧する API が無いため、`ms modules` と同じ一覧をモジュールマネージャーからリフレクションで読んでいます。
ModSharp の更新でその内部が変わった場合は、モジュールごとに読み込まれたアセンブリから一覧を作ります。そのときは表示名と状態が `-` になり、
作者はアセンブリの Company になります。
